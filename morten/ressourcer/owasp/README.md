# OWASP-ressourcer

Her samler jeg materiale fra OWASP om sikker udvikling og verifikation af webapplikationer.

- [Top 10 Proactive Controls](proactive-controls.md): Et overblik over ti områder, hvor udviklere kan forebygge sårbarheder.
- [ASVS – Application Security Verification Standard](asvs.md): Detaljerede sikkerhedskrav til design, implementering og test.

## Hvordan hænger ressourcerne sammen?

| Ressource | Hvad bruger jeg den til? |
| --- | --- |
| [OWASP Top 10:2025](https://top10.owasp.org/2025/) | Forstå centrale risici og konsekvenser ved sårbarheder. |
| [Proactive Controls](proactive-controls.md) | Lære principper og teknikker til at forebygge sårbarheder. |
| [ASVS](asvs.md) | Vælge konkrete sikkerhedskrav og efterprøve, om de er opfyldt. |
| [Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | Finde vejledning til at implementere sikkerhedsforanstaltningerne. |

Til undervisningen vil jeg koble en sårbarhed til en relevant Proactive Control og derefter vælge enkelte ASVS-krav til implementering og test. Ressourcerne har hver deres struktur og nummerering.

[Tilbage til alle ressourcer](../README.md).
