# Microsoft-ressourcer

Her samler jeg Microsofts materiale om trusselsmodellering og sikker softwareudvikling.

- [STRIDE](stride.md): Seks trusselskategorier som hjælp til at undersøge, hvad der kan gå galt i et system.
- [Security Development Lifecycle (SDL)](sdl.md): Sikkerhedsaktiviteter gennem udvikling og drift.

## Hvordan hænger ressourcerne sammen?

STRIDE kan bruges i den trusselsmodellering, som indgår i SDL. Microsoft beskriver sammenhængen i [SDL-praksis 3: Sikkert design og trusselsmodellering](https://www.microsoft.com/en-us/securityengineering/sdl/practices/secure-by-design).

Til valgfaget vil jeg bruge STRIDE til at finde konkrete trusler i en mindre webapplikation. SDL kan give overblik over, hvornår og hvordan vi arbejder med sikkerhed. [OWASP Proactive Controls og ASVS](../owasp/README.md) kan derefter hjælpe med forebyggende tiltag og konkrete krav til implementering og test.
