# Gør security til en del af måden, du udvikler på

## Hvorfor vælge dette valgfag?

Det meste software er forbundet til andre systemer, håndterer værdifulde oplysninger og afhænger af mere end selve koden. Security er derfor ikke noget, man først tilføjer til sidst. På dette valgfag lærer du at tænke security ind, når du designer, udvikler, tester og driver en application.

I stedet for kun at lære om security som en liste over threats følger du en realistisk web application gennem hele dens stack: fra browser og React frontend til Java API, database og deployment environment. Du lærer at opdage, hvor risici opstår, og træffe beslutninger om, hvordan de kan reduceres, baseret på konkret evidens.

## Hvad gør valgfaget anderledes?

- **Praktisk læring, ikke kun teori.** Arbejd med threat models, permissions matrices, code reviews, configuration reviews, tests, log analysis og incident response-øvelser.
- **Tæt på det daglige udviklingsarbejde.** Undersøg authentication, password storage, sessions, authorization, input validation, database queries, browser security, dependencies og CI/CD i en application.
- **Security, du kan verificere.** Øv dig i at omsætte krav til checks og underbygge dine konklusioner med testresultater, configuration og anden evidens.
- **Et bredere perspektiv.** Se, hvordan softwarevalg hænger sammen med Linux permissions, network boundaries, HTTPS, logging, phishing response og incident handling.
- **Arbejder, du kan forklare.** Afslut med konkrete resultater som en threat model, security tests, en beslutning om dependencies og en kort security report, som du kan præsentere til en jobsamtale.

## Danske hændelser fra nyhederne

Danske hændelser viser, at security har konkret betydning for både virksomheder, kritisk infrastruktur og deres kunder. De hænger direkte sammen med emnerne på valgfaget:

- **CloudNordic og AzeroCloud (2023):** Et ransomware-angreb satte de danske hostingfirmaers systemer ud af drift. Kunder mistede adgang til blandt andet hjemmesider, e-mail og data, og rapporteringen beskrev, at størstedelen af kundedata ikke kunne genskabes. Hændelsen viser betydningen af backup, recovery, netværksadskillelse og beredskab — også når man er afhængig af en ekstern cloud- eller hostingudbyder. [Radio4's dækning](https://radio4.dk/nyheder/mange-danske-virksomheder-er-ramt-af-hackerangreb-der-er-ingen-virksomhed-tilbage/) · [Data Center Dynamics' rapportering](https://www.datacenterdynamics.com/en/news/danish-hosting-firms-lose-all-customer-data-in-ransomware-attack/).
- **Angreb mod den danske energisektor (2023):** SektorCERT beskrev et koordineret angreb, hvor 22 danske energivirksomheder blev kompromitteret gennem sårbarheder i netværksudstyr. Det viser, hvorfor patch management, netværkssikkerhed, overvågning og hurtig incident response er vigtige — især i kritisk infrastruktur. [SektorCERTs rapport](https://sektorcert.dk/wp-content/uploads/2023/11/SektorCERT-The-attack-against-Danish-critical-infrastructure-TLP-CLEAR.pdf) · [SecurityWeeks omtale](https://www.securityweek.com/22-energy-firms-hacked-in-largest-coordinated-attack-on-denmarks-critical-infrastructure/).

## Hvorfor er det relevant på dit CV?

Arbejdsgivere har brug for udviklere, der ikke kun kan få software til at virke, men også kan opdage risici, vælge relevante sikkerhedsforanstaltninger og forklare, hvordan de har verificeret dem. På valgfaget får du øvelse i at beskrive de kompetencer med konkrete eksempler frem for blot at nævne security-buzzwords.

Du får erfaring med secure development practices som:

- threat modeling og risk prioritization;
- authentication, session handling og authorization;
- input validation og parameterized database queries;
- browser protections som XSS- og CSRF prevention;
- security reviews af dependencies og CI/CD;
- security logging, incident response og verificering mod udvalgte OWASP ASVS requirements.

Det er nyttige kompetencer for application developers, testers, DevOps engineers og alle, der arbejder med systemer, som behandler brugerdata.

## Et stærkt supplement til din uddannelse

Vælg valgfaget, hvis du vil forstå ikke bare, hvordan man bygger en application, men også hvordan man udfordrer dens antagelser, tester dens beskyttelse og formidler, hvilke risici der stadig er. Viden om security erstatter ikke dine andre tekniske kompetencer; den hjælper dig med at bruge dem mere ansvarligt og gør det lettere for andre at have tillid til dit arbejde.

### Eksempel på en CV-beskrivelse

Tilpas teksten, så den kun beskriver arbejde, du faktisk har udført:

> Arbejdede med secure development i en web application bygget med React og Java: udarbejdede en threat model, testede authentication og authorization, validerede input handling, gennemgik dependencies og CI/CD configuration og dokumenterede security findings med tilhørende evidens.
